A panel for picking one entry out of grouped sets. It knows nothing about icons or emoji: an entry is a value with a name , and how it looks is decided by a template. Emoji work out of the box because the default template renders value as text.

The picker is presentational — put it inside tui-dropdown , tui-sheet or a dialog yourself. The search field is projected, so you own its appearance, placeholder and debounce.

Groups of entries. Order is yours — the top row of tabs follows it, and each tab uses the group's icon . Clicking a tab scrolls to its group rather than filtering to it. Currently picked entry, compared by value . Controlled: the picker highlights it but never stores it. Search query. It comes from the field you project, the picker only filters by it. Filters and orders groups in one pass. Defaults to a case-insensitive substring over name and tags . Pass null to disable filtering entirely — for server-side search, where groups already arrive filtered. How to render an entry. Defaults to printing value as text. Shown when nothing matches, and when groups is empty. Defaults to the localized nothingFoundMessage . Emits the whole entry, so your own fields survive the round trip. Picking a variant emits the variant.

Variants

An entry may carry variants — skin tones for emoji, weights for an icon set. They are never listed inline: hold the entry with a pointer, or press Alt + Enter on it, and they pop up. Entries that have them are marked with a corner dot.

Keyboard

Move around the grid. From the projected search field, ↓ enters the grid. First and last entry of the current group. Open variants of the focused entry.
